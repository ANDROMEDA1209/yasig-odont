# Recursos gráficos

El usuario incorporó el logotipo `public/assets/images/gallery/Logo.jpeg` y el banner `public/assets/images/gallery/banner.jpeg`. Ambos originales se utilizan directamente, completos y sin deformación. El componente compartido aplica el logotipo en encabezados, pie, login, barra lateral y comprobantes; el banner se muestra exclusivamente en la web pública, no en el acceso ni en el dashboard. Como alternativa para el logo se mantiene `public/assets/images/brand/logo.png`.

Las fotografías se descargaron y optimizaron a WebP; no existen dependencias remotas en la interfaz. Son referencias, señaladas como tales, y no describen instalaciones de Yasig Odont:

- `clinic.webp`: Benyamin Bohlouli, [White and blue hospital bed](https://unsplash.com/photos/white-and-blue-hospital-bed-hmVZ7StKY7I), Unsplash.
- `room.webp`: Ozkan Guner, [A dental room with a purple chair and a white desk](https://unsplash.com/photos/a-dental-room-with-a-purple-chair-and-a-white-desk-0gI0IXURDgo), Unsplash.
